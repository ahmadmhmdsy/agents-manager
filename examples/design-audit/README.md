## Subject

**Stride** — fictional fitness tracking app. Already shipped for iOS and Android. PM wants an independent audit before the next major release.

## What this example demonstrates

- AUDIT mode (no new design, just findings)
- EVALUATE mode (accessibility focus)
- Severity matrix with P0/P1/P2/P3 ranking
- Remediation plan with phases
- Audience = PM (executive view) + dev team (concrete fixes)
- Strict separation: no redesign produced, only analysis

## What this example does NOT include

- New mockups or design proposals (would be separate dispatches)
- Brand work (Stride brand pre-exists)
- Component library changes (audit only recommends; doesn't deliver)
- Interactive prototype (audit is a written report)
