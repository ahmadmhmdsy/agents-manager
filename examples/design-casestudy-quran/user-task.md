# Retrospective user task — Quran app design system

This is a **retrospective example**, not a live worked pipeline. The "user task" below is reconstructed from the original brief documented in [`README.md`](README.md) and the lessons in [`lessons.md`](lessons.md).

**Original user task (reconstructed):**

> "We're building an iOS/Android Quran reader for the Saudi Arabian market. The app needs to feel spiritually appropriate — modern but rooted, clean but not sterile. We need a design system that supports 4 distinct visual themes: (1) modern minimal, (2) traditional illuminated manuscript, (3) Apple-contemporary, (4) Saudi-Arabian contemporary. Each theme must support Arabic + English + Urdu with proper RTL, RTL-aware layout, and dual Hijri/Gregorian calendars. We have 1 year and 3 designers. What's the design system that makes this tractable?"

**What this example IS:** a postmortem of the design decisions made in the 6 months before `am-design` was formalized. Captures the patterns that worked and the ones that should be encoded into the new agent.

**What this example IS NOT:** a step-by-step pipeline trace. The original work was done before agents-manager existed. The artifacts in this directory (`lessons.md`, `mapping.md`, `retrospective.md`) are the documentation of past decisions, not live deliverables.

See [`README.md`](README.md) for the full retrospective.
