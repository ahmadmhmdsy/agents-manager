# Notes

Free-form notes and handoffs between agents. See `../README.md` for the full naming and ownership rules.

Typical contents:
- `01_research_<task-id>.md`
- `02_plan_high_<task-id>.md`
- `02_plan_phases_<task-id>.md`
- `03_coder_summary_<task-id>_<phase>.md`
- `99_decisions.md` (append-only)
- Feedback notes from one phase to the next (e.g. `feedback_review_to_coder_<task-id>_<phase>.md`)
